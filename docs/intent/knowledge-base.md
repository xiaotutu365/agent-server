# 意图声明：知识库功能完善

> 来源：interview-me 访谈（2026-10-16），经用户确认。
> 状态：Confirmed

## Outcome

知识库自底向上补齐四层：

1. **L1 环境**：Qdrant 环境跑通（本地开发可验证）
2. **L2 文档管理**：已上传文档可见（列表、片段数）、可删单个文档；上传有进度反馈
3. **L3 检索调优**：分块/嵌入/检索参数可调整，调整后可在工作区直接预览检索效果（评分/来源可见）
4. **L4 Agent 集成**：智能体编辑页勾选挂载哪些知识库（与 MCP 挂载同套路），对话时自动检索相关片段注入上下文

UI 一并优化，沿用现有设计系统（列表页 + 模态窗模式）：

- L2：文档列表 + 删除/上传进度
- L3：调参后检索预览（评分/来源）
- L4：智能体编辑页「知识库挂载」勾选区
- 聊天消息：AI 回答中的引用来源渲染成可识别的来源标记

## User

用户本人（管理员），单人本地使用。

## Why now

知识库目前只有雏形：上传后是黑盒（看不到传了什么、删不掉单个文档）、检索效果无法验证、和智能体完全没打通。

## Success

问一个**只有文档里才有答案**的问题，agent 能正确回答并附**引用来源**（哪个文档、哪个片段）。

## Constraint

复用现有栈：Qdrant + 配置页已有的嵌入模型设置 + 现有 RBAC。不引入新中间件。

## Out of scope

- OCR / 扫描件解析
- 网页爬取入库
- 文档级权限（沿用现有 RBAC 粗粒度）
- 多租户共享库
- 引用全文预览弹窗（第一期只显示来源信息）
