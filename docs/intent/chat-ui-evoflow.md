# 意图：聊天窗口 EvoFlow 风格改版

- 日期：2026-10-18
- 原始需求：截图 `docs/requirements/b35d20344be5cbe62cafffbd445056dd.jpg`（EvoFlow v1.0.3 聊天界面）
- 状态：已经 interview-me 确认（用户明确 OK）

## 意图陈述

聊天窗口整体改版，对标 EvoFlow 的「agent 执行过程透明化」体验，三块都做：

1. **消息流内联执行过程**：任务清单（可勾选✓）、命令/工具执行日志、「思考中…」折叠项直接呈现在对话流里，替代现有顶部「任务清单」按钮+面板
2. **输入区功能位**：左侧「+」上传文件供本轮对话使用（技术路径 spec 定）；「深度思考」先做可切换的样式占位，不接模型能力
3. **整体观感**：顶部会话标题栏（含运行状态）、留白、圆角卡片风格

## 关键决策

| 决策点 | 结论 |
|---|---|
| 范围 | 三块全做，一次改版交付 |
| 任务清单去留 | 内联在消息流，顶部按钮+面板移除 |
| 深度思考 | 样式占位（可切换状态），不接模型 reasoning |
| 「+」按钮 | 上传文件进对话（供 agent 使用），技术路径 spec 阶段定 |
| 配色 | 跟随现有主题变量（亮/暗双主题），不照搬 EvoFlow 配色 |
| 数据来源 | 优先用后端已有事件/数据，确需新接口在 spec 定 |
| EvoFlow 产品导航 | 不做（任务中心/工作流/员工等，本项目有自己的菜单体系） |
| 会话级选模型 | 另行立项，不在本次（此前访谈已确认方案，挂起） |

## 成功标准

- 发消息后，任务进度/工具执行直接在对话流可见、任务可勾选
- 输入区「+」「深度思考」可用（+ 真上传，深度思考为占位）
- 会话列表、HITL 确认、重试、停止等现有功能不回退
- 亮/暗主题下均正常渲染
